## 1. 项目目标

个人站点，三类内容，三种权限边界：

- **技术文档** — 公开，需 SEO
- **小网页 Demo** — 纯静态，需口令才能进
- **个人日记** — 仅本人可写可改；授权者可读但不可改；本人手机可读不可写

## 2. 三层模型

| 层 | 内容 | 边界 | 机制 | 内容存哪 |
|---|---|---|---|---|
| **L0 公开** | 技术文档 | 全网 + 搜索引擎 | Astro 静态产物，nginx 直出 | Git 里的 Markdown |
| **L1 口令** | 静态 Demo | 知道口令的人 | **nginx Basic Auth**（5 行配置） | 服务器目录 |
| **L2 私密** | 个人日记 | 作者写 / 授权者读 | 客户端信封加密 + WebAuthn + 服务端写白名单 + Ed25519 签名 | SQLite 存密文 |

## 3. 三条核心原则

1. **安全边界由渲染/存储路径决定，不由前端 JS 决定。** 纯静态站做不了真密码——内容进了 bundle，F12 或直接 fetch 就全拿到。
2. **「谁能读」「谁能写」「内容是否可信」是三套独立机制**，分别对应加密层、服务端鉴权层、签名层。混在一起想必然出错。
3. **能读就能拷贝。** 加密防的是服务器和网络，不是已授权的人。没有 DRM 这回事。

## 4. 部署决策（终版）

### 现状

- 域名：注册/托管在 Cloudflare
- 服务器：阿里云 **2C4G，中国大陆地域**
- **ICP 备案已完成**，接入商为阿里云，且关联的就是这台实例

**这是最理想的情况。** 前两版围绕"未备案"设计的所有绕行方案（换境外服务器、整站托管 Cloudflare Pages）全部作废——那些是在解一个你并不存在的问题。

### Cloudflare 的正确用法：不用

| 用法 | 可行性 | 结论 |
|---|---|---|
| **灰云**（仅 DNS 解析，不代理） | 可行、不影响备案 | **收益为零**——阿里云 DNS 对大陆解析更快 |
| **橙云**（代理流量） | 技术上能开 | **有害**——免费版无中国节点，大陆流量绕美国再回源 |
| **Cloudflare Access** 门禁 | 必须开橙云 | **不可用**——用它等于放弃备案换来的速度 |

Cloudflare 免费版在中国大陆没有机房，大陆访问会被路由到美国节点，国内圈子里管这叫"**减速 CDN**"。开了之后：

```
现在（直连）：   大陆用户 ──────────────> 你的阿里云            快
开橙云之后：     大陆用户 ──> 美国 CF 节点 ──> 你的阿里云        出境一趟再绕回来
```

> **备案的全部价值就是"大陆用户直连、访问快"。任何把流量绕出境的方案都在抵消这个价值。**
>
> 建议顺手把 DNS 解析也切回阿里云（万网 DNS）。域名注册在 Cloudflare 不影响所有权，只是解析交给国内更快、也彻底避开"备案域名用境外 DNS"的说法分歧——反正在你这个场景下 Cloudflare DNS 没有任何收益，没好处的事不值得冒任何不确定性。

### 最终架构：一台服务器，nginx 按子域分流

```
                          ┌── yourdomain.com          L0  Astro 静态产物
                          │     无鉴权 · 可索引
                          │
用户 ──直连──> nginx ──────┼── lab.yourdomain.com      L1  静态 demo
   （不绕 CDN，不出境）      │     nginx Basic Auth
                          │
                          └── journal.yourdomain.com  L2  React SPA
                                ├─ /       → 静态文件
                                └─ /api/*  → 127.0.0.1:8000 (FastAPI)
                                                └─ SQLite（只存密文）
```

### 子域名不需要单独备案

阿里云规则：**备案只针对顶级域名。** 主域备案通过后，`lab.` / `journal.` 等子域可直接建站使用，不计入备案网站数量限制，无需额外提交。

### 备案带来的两项硬性义务（容易漏）

1. **网站首页底部必须展示 ICP 备案号**，并链接到 `https://beian.miit.gov.cn`。管局会抽查，缺失会被通知整改。
2. **公安联网备案**：网站上线 30 日内需在 `www.beian.gov.cn` 完成，取得编号后同样展示在首页底部。

> 个人日记是非公开的个人数据，不构成对外提供的互联网信息服务。需要按常规注意内容合规的是 L0 公开文档部分。
