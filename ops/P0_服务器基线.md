## Step 2 · MySQL 探测（共用实例，先看版本再动）

```bash
sudo bash 02_mysql_probe.sh
```

关键输出确认：
- **版本** → 决定 redo 写法（⑪ Q6a）：
  - `8.0.30+` → 用 `innodb_redo_log_capacity`（在线可改）
  - `8.0.0–29` → `innodb_log_file_size`（需重启）
  - `5.7` → 需重启 + 手工处理旧 redo；且 `utf8mb4_0900_ai_ci` 不存在，把所有 `utf8mb4_0900_ai_ci` 换成 `utf8mb4_unicode_ci`
- **现有账号的 host**：若走 TCP 的 `@'localhost'` 账号存在，开 `skip_name_resolve` 前先补 `@'127.0.0.1'`

**调优**：编辑 `/etc/mysql/my.cnf`（或 `/etc/mysql/mysql.conf.d/mysqld.cnf`），按 ②/③ 的参数段设置：
```ini
[mysqld]
bind-address = 127.0.0.1
innodb_buffer_pool_size   = 512M
innodb_buffer_pool_instances = 1
# 8.0.30+ 用这个（替代下面 log_file_size）
innodb_redo_log_capacity  = 128M
# 8.0.0–29 或 5.7：
# innodb_log_file_size  = 128M
innodb_flush_method       = O_DIRECT
innodb_flush_log_at_trx_commit = 1
max_connections           = 60
table_open_cache          = 400
tmp_table_size            = 32M
max_heap_table_size       = 32M
sort_buffer_size          = 512K
join_buffer_size          = 512K
character-set-server      = utf8mb4
collation-server          = utf8mb4_0900_ai_ci
performance_schema           = ON
performance_schema_max_table_instances = 400
performance_schema_max_table_handles  = 800
```

> `performance_schema` 是学习价值 vs 内存的取舍，当前保留并缩小（2C4G 可接受）。若其他项目吃紧可关掉省 200–400 MB。

重启并验证：
```bash
sudo systemctl restart mysql
mysql -uroot -p -e "SELECT @@innodb_buffer_pool_size/1024/1024, @@performance_schema;"
```

## Step 5 · nginx 配置 + 证书

```bash
# 安装 nginx（若未装）
sudo apt update && sudo apt install -y nginx

# 拷配置（占位符域名已在文件里写死为 leyanwc.xyz）
sudo cp deploy/nginx/public.conf /etc/nginx/sites-available/leyanwc-public
sudo cp deploy/nginx/lab.conf    /etc/nginx/sites-available/leyanwc-lab
sudo cp deploy/nginx/journal.conf /etc/nginx/sites-available/leyanwc-journal
sudo ln -s /etc/nginx/sites-available/leyanwc-* /etc/nginx/sites-enabled/

# Basic Auth 用户文件（L1）
sudo htpasswd -c /etc/nginx/.htpasswd-lab guest   # 首次创建；以后追加用 htpasswd（不带 -c）
sudo chown root:www-data /etc/nginx/.htpasswd-lab
sudo chmod 640 /etc/nginx/.htpasswd-lab

# 证书（三个子域一张 SAN）
sudo certbot --nginx -d leyanwc.xyz -d www.leyanwc.xyz -d lab.leyanwc.xyz -d journal.leyanwc.xyz

# 验证自动续期
sudo certbot renew --dry-run
```

> 我的 nginx 配置里证书路径是注释，certbot `--nginx` 会自动填入。

## Step 6 · systemd：journal-api（L2 后端）

- 前置：FastAPI 应用位于 `/srv/blog/packages/journal/api`（P3 阶段才部署代码，P0 先建好 unit 占位）
- 安装 unit：

```bash
sudo cp deploy/systemd/journal-api.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable journal-api
```

- 配置里的 `User=` 应改为运行用户（如 `www-data` 或专用 `journal` 用户），并保证该用户对目录有读权限。
