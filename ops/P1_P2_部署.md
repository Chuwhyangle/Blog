# P1 + P2 · L0 公开站 + L1 Demo 区部署

> 前置：P0 已完成（nginx + 证书 + 基本目录就绪）。
> 两个包都是**纯静态**，部署 = 构建 + rsync 到服务器目录。

---

## P1 · L0 部署（leyanwc.xyz）

### 1. 构建

```bash
cd packages/public
npm ci
npm run build        # 产物在 dist/
```

### 2. 同步到服务器

```bash
# 本地执行（假设服务器别名 myserver 已配好）
rsync -az --delete packages/public/dist/ myserver:/var/www/public/
```

> `rsync -az`：压缩传输 + 保留权限；`--delete` 清理远端旧文件。
> 首次部署确保服务器 `/var/www/public` 存在、nginx 用户可读。

### 3. 验证

```bash
curl -I https://leyanwc.xyz/
curl -s https://leyanwc.xyz/ | grep -o 'ICP备案号[^<]*'
# 访问 /posts/hello/ 有文章内容
```

## P2 · L1 部署（lab.leyanwc.xyz）

### 1. 拷贝 demo 文件

```bash
rsync -az packages/lab/ myserver:/var/www/lab/
```

### 2. 创建 Basic Auth 用户（首次）

```bash
# 服务器上执行（需要 sudo）
htpasswd -c /etc/nginx/.htpasswd-lab guest   # 首次创建用户 guest
chown root:www-data /etc/nginx/.htpasswd-lab
chmod 640 /etc/nginx/.htpasswd-lab
```

以后加用户（**不带 -c，避免覆盖**）：
```bash
htpasswd /etc/nginx/.htpasswd-lab alice
```

### 3. 重载 nginx

```bash
sudo nginx -t && sudo systemctl reload nginx
```

### 4. 验证

```bash
# 无凭据 → 401
curl -i https://lab.leyanwc.xyz/ | head -8
# 带凭据 → 200
curl -u guest:PASSWORD -I https://lab.leyanwc.xyz/
```

## 部署脚本收纳（可选进阶）

两个部署动作未来可以合并成一个：

```bash
#!/usr/bin/env bash
# deploy.sh —— 一键部署 L0 + L1
set -euo pipefail
SRV=myserver   # ssh 别名

cd "$(dirname "$0")/.."
(cd packages/public && npm run build)
rsync -az --delete packages/public/dist/ "$SRV:/var/www/public/"
rsync -az packages/lab/ "$SRV:/var/www/lab/"
echo "部署完成: https://leyanwc.xyz"
```

放 `deploy/scripts/deploy_l0_l1.sh`，以后加内容就两步：写 Markdown → 跑脚本。
